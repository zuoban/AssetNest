# AssetNest UI/UX 设计规范

## 1. 设计理念与美学定位

AssetNest 是面向跨境电商卖家的**专业桌面级数字资产工作台**（Desktop-first Web Application），设计目标是“克制、清晰、高信息密度、零视觉噪音”：

- **视觉基调**：浅色专业工具风格（P0 聚焦浅色模式的高品质打磨，不为 P1 主题切换引入多余框架）。
  - 主画布：`#F8F9FA`（柔和微灰，凸显商品图主体）
  - 卡片/侧栏表面：`#FFFFFF` + `1px solid #E5E7EB` 细描边（弱阴影、高边界清晰度）
  - 强调色：`#2563EB`（专业钴蓝，用于主操作、当前选中态、焦点框）
  - 主文本：`#111827`，次级文本：`#4B5563`，元数据/提示：`#6B7280`
- **排版体系**：
  - 中文界面优先：`system-ui, -apple-system, "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif`
  - 泰文/英文内容兼容：`Noto Sans Thai` 回退，确保 PDP 编辑器与搜索结果泰文音调符号不截断；
  - 等宽数据：`ui-monospace, SFMono-Regular, Menlo, monospace` + `tabular-nums`，用于 SPU、SKU 编码、分辨率（`1000×1000`）、比例（`1:1`）、文件体积、SHA-256 摘要、Release 编号（`R003`）。
- **非颜色唯一标识原则**：所有状态（锁定母图、当前版本、已冻结快照、存储离线）必须同时具备 **图标 + 中文文本标签 + 语义色块**，绝不单靠色点表达。
- **真实性约束**：每个按钮、统计数字、列表项都必须来自真实后端 API；尚未开发的后续里程碑菜单绝不渲染假数据或空壳按钮。

## 2. 信息架构与桌面布局

```text
┌──────────────┬─────────────────────────────────────────────────────────┐
│ 左侧导航栏   │ 顶部上下文栏（面包屑 / 全局搜索框 / 快捷操作 / 任务指示器）│
│  220px 固定  ├─────────────────────────────────────────────────────────┤
│              │                                                         │
│ · 工作台     │                   主内容工作区                          │
│ · 商品中心   │   （商品中心：网格/列表切换；全部素材：三栏布局；         │
│ · 全部素材   │     上架工作台：渠道分栏 + 拖拽轮播 + PDP 编辑器）       │
│ · 上架工作台 │                                                         │
│ · 店铺管理   │                                                         │
│ · 回收站     │                                                         │
│ · 设置       │                                                         │
│              │                                                         │
│ [管理员/退出]│                                                         │
```

- **响应式底线**：针对 `1280px`–`1920px+` 桌面宽屏优化；当窗口窄于 `1024px` 时左侧导航折叠为抽屉，右侧属性面板可抽屉展开，移动端支持浏览、检索与查看详情。

## 3. 核心页面交互规范

### 3.1 首次初始化与登录（M0）
- 居中极简卡片（最大宽 `440px`），清晰展示品牌标识、本地 SQLite 与默认存储就绪状态；
- 初始化引导明确提示“创建唯一管理员账号”及宿主机密码恢复说明；
- 错误提示内联可读（如登录限速剩余时间、密码强度校验），禁止裸露技术堆栈。

### 3.2 工作台（M0 起逐步充实真实数据）
- 顶部核心统计卡（商品总数、素材总数、草稿 Listing），全部来自 SQLite 真实计数；
- 快捷动作栏（随里程碑逐步启用已实现入口）；
- 下方两栏：左侧为「后台任务队列」（运行中进度条/阶段 + 失败重试入口），右侧为「最近系统活动」（脱敏审计流）。

### 3.3 商品中心与商品详情（M1 / M3）
- 列表支持**封面卡片网格**与**高密度表格**切换，卡片展示封面图、SPU（等宽）、中/英文名、SKU 数、素材数、关联渠道数与业务状态。
- 商品详情采用 5 个标签页：`概览与规格`、`SKU`、`素材与母图`、`上架链接`、`上架历史`。

### 3.4 全部素材三栏工作台（M1）
- **左栏（`220px`）**：快捷视图（全部、待归类、收藏）、逻辑文件夹树、多维标签筛选（市场/平台/用途/颜色/场景）、存储空间筛选；
- **中栏（自适应）**：顶部组合筛选与搜索栏（支持中/泰/英实时检索与排序）、批量选择工具条、虚拟化网格/列表（`@tanstack/react-virtual` 支持 5 万条流畅滚动）、拖拽上传蒙层；
- **右栏（`320px`）**：选中素材属性检查器（原图信息、当前版本 badge、历史版本列表、母图状态、标签、所属商品、存储位置与在线/离线提示、下载原图）。
- **全屏灯箱预览（Lightbox）**：支持滚轮/按钮缩放、适屏与 `100%` 切换、键盘 `←/→` 切图、`Esc` 关闭；视频展示原生播放器与不支持 Range 时的明确提示；文本/MD 安全纯文本预览；不可解码格式（PSD/RAW/ZIP）展示类型图标与原文件下载按钮。

### 3.5 母图与素材版本并排对比（M3）
- 对比视图左侧显示锁定母图，右侧显示选定的素材版本；
- 底部并列展示分辨率、宽高比、文件大小、外观约束清单（结构/比例/颜色/尺寸/禁止修改项），方便核对素材细节。

### 3.6 上架工作台与 PDP 编辑器（M3 / M4）
- 顶部切换当前商品下不同店铺/市场的 Listing，并醒目展示目标渠道（如 `Shopee · PH · StoreA · EN`）及明确提示“外部平台发布状态由人工维护”。
- **素材集合**：轮播图支持 `@dnd-kit` 拖拽排序（第 1 位自动标“主图”）、分辨率和比例、重复项警示及“有新版本可手动升级”提示（绝不静默替换）；详情图支持连续竖向瀑布预览（兼容 `9:16`）；SKU 图以每个 `Listing SKU` 行独立槽位精确绑定。
- **PDP 编辑器**：结构化字段（标题、短描述/卖点、完整描述、规格表、包装清单、使用说明、SEO 关键词）+ 标题 Unicode 码点实时计数 + 一键导入商品公共规格（差异提示不覆盖）+ 一键复制单字段/全文 + 版本冻结与历史恢复。
- **检查与导出（M4）**：清晰区分红色「阻断错误」与琥珀色「提醒项」；正式 Release 创建与明确标注的「草稿导出包」按钮分离；历史 Release 列表支持随时重新流式生成 ZIP 并查看 `manifest.json` 摘要。

## 4. 异常与离线态体验

- **远程存储离线 / 配置缺失**：页面顶部展示非阻断提示条，本地业务元数据照常浏览；受影响素材缩略图区域标示「存储离线」徽章并提供重试，不崩溃白屏。
- **耗时任务（上传/迁移/打包/备份）**：全局右上角任务抽屉展示阶段与已处理条数，失败展示可读错误与「重试」按钮。
- **危险操作**：删除商品（含历史引用清单提示）、解除/替换母图、确认清理迁移来源对象、执行全量备份恢复，均需明确二次确认弹窗。
